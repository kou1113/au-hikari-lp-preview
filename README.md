# auひかり 新居のお申し込み案内 LP

社内確認用の静的HTMLです。GitHub Pages、または `index.html` をブラウザで開いて確認できます。

フォームはプレビュー専用です。入力内容は送信・保存されません。

## デザインパターン

- 通常の `index.html` はパターン2です。今後の修正はこちらへ反映します。
- パターン1は保存版として、`index.html?pattern=1` で確認できます。
- パターン1用の画像・スタイルは削除せず保持しています。

## 公開前に差し替えるもの

- 運営会社名、所在地、代表者名
- 電話番号と `tel:` リンク
- 代理店届出番号
- プライバシーポリシー、個人情報の取り扱いページへのリンク
- フォームの送信先と確認・完了画面
- KDDI・代理店契約上の広告審査で指定された表記
- Google広告のコンバージョンタグ、GA4などの計測タグ

## WordPress移植時

固定ページ用テンプレートへHTMLを移し、CSSとJavaScriptをテーマまたは子テーマから読み込みます。フォームは、会社で採用するフォームプラグインか自社の送信先に接続してください。
